##  ▍Who I am

I'm **GILD** — mostly self-taught, developer and reverse engineer.

I spend most of my time taking things apart to understand how they actually work.

That can mean a native binary, an Android application, a heavily minified JavaScript bundle, an obfuscated Python project, a protocol, or a protection layer. I trace execution, inspect behavior, reconstruct logic, and keep digging until the internals make sense.

My strongest area is **JavaScript and Python deobfuscation**, but I also work with native binaries, mobile applications, network traffic, runtime behavior, and modern anti-bot systems.

I build things too — backend services, web applications, automation tools, developer utilities, and whatever else is needed to turn an idea into something working.
